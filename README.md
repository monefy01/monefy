# The Debt Freedom Method — Monefy

Landing page oficial de alta conversão para o produto **The Debt Freedom Method** da Monefy.

---

## 🚀 Como subir este projeto para o GitHub

Se você já tem o Git instalado no seu computador, siga os passos abaixo no terminal dentro da pasta descompactada:

```bash
# 1. Inicializar o repositório git local
git init

# 2. Adicionar todos os arquivos
git add .

# 3. Criar o primeiro commit
git commit -m "Initial commit: Monefy Debt Freedom Method landing page"

# 4. Renomear a branch principal para main
git branch -M main

# 5. Conectar com o seu repositório no GitHub (substitua com o link do seu repo)
git remote add origin https://github.com/SEU_USUARIO/NOME_DO_REPOSITORIO.git

# 6. Enviar para o GitHub
git push -u origin main
```

---

## 🛠️ Como rodar o projeto localmente

Para rodar a versão React + Vite completa com WebGL e efeitos visuais:

```bash
# 1. Instalar as dependências
npm install

# 2. Iniciar o servidor de desenvolvimento
npm run dev
```

Abra no navegador em: `http://localhost:3000` ou `http://localhost:5173`.

## 🌐 Como fazer deploy gratuito

### Opção 1: Vercel (Recomendado)
1. Acesse [vercel.com](https://vercel.com) e faça login com sua conta do GitHub.
2. Clique em **"Add New Project"**.
3. Selecione o repositório que você acabou de subir.
4. O framework Vite será detectado automaticamente. Clique em **"Deploy"**.
5. Em menos de 1 minuto seu site estará no ar com HTTPS gratuito!

### Opção 2: Netlify
1. Acesse [netlify.com](https://netlify.com) e conecte com o GitHub.
2. Selecione o repositório.
3. Build command: `npm run build`
4. Publish directory: `dist`
5. Clique em **"Deploy site"**.

### Opção 3: GitHub Pages (Versão Standalone)
Use o arquivo `index_standalone.html` renomeando-o para `index.html` na raiz de um repositório configurado para GitHub Pages.
